# SSD1306 Lib

SSD1306 Lib is a minimal, easy-to-use library for 128x64 0.96" monochrome OLED displays.  
It communicates with the display using I2C at address 0x3C.

The library provides functions to initialize the display and control its power.  
You can set individual pixels, draw lines, rectangles, and filled shapes.  
It also supports drawing text using custom fonts.

You can clear or fill the internal display buffer quickly.  
It allows adjusting contrast and inverting the display.  
Basic scrolling functions are included for simple animations.  
Designed to be lightweight and easy to understand for beginners.  
Perfect for learning OLED control or integrating into small Arduino projects.
